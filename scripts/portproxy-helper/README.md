# Helpers

Набор небольших служебных скриптов.

## PortProxy Helper

`scripts/portproxy-helper.bat` — пакетный скрипт Windows для управления
правилами `netsh interface portproxy` (v4→v4) с дублированием правила v6→v4.

### Возможности
- добавление или обновление правила перенаправления (создаётся пара v4→v4 и v6→v4);
- перезапуск службы IP Helper для сброса существующих соединений;
- удаление отдельных правил или всех сразу;
- отображение текущей конфигурации PortProxy;
- отображение активных соединений на выбранном порту;
- автоматическое создание правил брандмауэра для выбранного порта.
- автоматическое восстановление после перезагрузки или повторного подключения к сети.

### Использование
1. Запустите `scripts/portproxy-helper.bat` в Windows. При необходимости
   скрипт перезапустит себя с правами администратора и закроет исходное окно.
2. Выберите пункт меню.
3. Следуйте подсказкам для настройки прокси.

При выборе пункта **7** скрипт добавляет две задачи Планировщика
Windows: одна перезапускает службу **IP Helper** через 30 секунд после запуска
системы, а другая — через 10 секунд после появления сетевого подключения.
Это сбрасывает зависшие TCP-соединения PortProxy. Краткий обрыв действующих
соединений в момент восстановления является нормальным. Пункт **8** удаляет
обе задачи и отключает автоматическое восстановление. Рабочий файл и журнал
располагаются в `C:\ProgramData\PortProxyHelper`; пункт **0** меню показывает
состояние задач и последние записи журнала.

IP‑адрес назначения по умолчанию можно изменить, отредактировав переменную
`DEFAULT_DEST_IP` в начале скрипта. При добавлении правила скрипт
автоматически открывает выбранный порт в брандмауэре для всех IP‑адресов.
